# AERIS Data Directory

This directory manages historical, validated, and processed air quality datasets alongside statistical metadata profiles.

## Directory Structure & Key Files

* `raw/`: Raw, unmutated source datasets.
  * **Primary Dataset:** `data/raw/city_day.csv` (CPCB historical multi-city Indian daily air quality records).
  * **Immutable Policy:** The raw dataset is strictly read-only and is never modified, overwritten, or altered during data ingestion.
* `processed/`: Validated, normalized tabular datasets.
  * **Ingested Parquet:** `data/processed/cleaned_city_day.parquet` (Cleaned, schema-validated tabular dataset generated by the ingestion pipeline).
* `metadata/`: Profiling and audit metadata.
  * **Profile Metadata:** `data/metadata/dataset_profile.json` (Automated data audit containing column dtypes, missingness distributions, date spans, pollutant availability, and numeric summaries).

## Data Ingestion & Validation Pipeline (Milestone 3)

To execute the data ingestion and validation pipeline, run:

```bash
python scripts/ingest_city_day.py
```

Optional CLI parameters:
```bash
python scripts/ingest_city_day.py \
  --raw-path data/raw/city_day.csv \
  --output-parquet data/processed/cleaned_city_day.parquet \
  --metadata-path data/metadata/dataset_profile.json
```

### Ingestion Scope
* Enforces strict schema definitions and data type normalization (`City` -> string, `Date` -> datetime64, pollutants & AQI -> float64, `AQI_Bucket` -> string).
* Performs integrity audits for duplicate rows, duplicate `(City, Date)` pairs, invalid dates, and non-numeric values.
* Generates metadata profiling reports without modifying the raw CSV.

## Exploratory Data Analysis & Quality Reports

To execute the full exploratory data analysis and generate report visualizations:

```bash
python scripts/run_eda.py
```

* **Interactive Notebook:** `notebooks/01_exploratory_data_analysis.ipynb`
* **JSON Analysis Report:** `outputs/eda/eda_report.json`
* **Visualization Figures:** `outputs/eda/figures/` (contains 9 high-resolution diagnostic plots)

## Future Machine Learning Preprocessing (Milestone 4)

ML-specific transformations are strictly decoupled from data ingestion/EDA and will be implemented in **Milestone 4 — Data Preparation**:
* Chronological partition splitting (70% Train, 15% Validation, 15% Test) without temporal leakage.
* City-aware localized linear interpolation for missing values.
* Feature scaling (`RobustScaler` / `MinMaxScaler`) fitted strictly on training partitions.
* Sliding lookback window generation ($T = 30$ days) for single-day-ahead ($t+1$) AQI forecasting.

## Version Control Policy
Raw datasets (`*.csv`, `*.parquet`) and processed binary data files are ignored by git via `.gitignore` to prevent repository bloat while maintaining 100% deterministic reproducibility via the ingestion script.
