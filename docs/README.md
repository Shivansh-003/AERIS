# AERIS Technical Documentation

This directory contains technical documentation, design records, API schemas, and architecture guides for the AERIS platform.

Core technical documentation files are located at the root of the repository:
* `PROJECT_SPEC.md` — System requirements and research objectives.
* `ARCHITECTURE.md` — Three-tier system architecture and data pipeline design.
* `DEVELOPMENT_PLAN.md` — 9-milestone engineering roadmap.
* `RESEARCH_BASELINE.md` — Research baseline, hypotheses, and evaluation protocols.
* `MODEL_SPECIFICATION.md` — Mathematical formulations for 8 model families and fuzzy attention.
* `API_SPECIFICATION.md` — OpenAPI 3.1 REST contracts.
* `DASHBOARD_SPECIFICATION.md` — User interface design and analytical view specifications.
